# Leadboard

A voice-first team lead cockpit, built for a lead with ADHD.

Replaces the paper notebook: he talks, the system structures. Morning standup becomes
a 5-minute guided ritual instead of a blank page. Dev performance (rework, deliveries,
deadlines) is derived from work that already happens — never hand-maintained.

## Layout

- `fe/` — Vite + React 19 client
- `be/` — Express + MongoDB API
- `docs/` — approach, user flows, data model
